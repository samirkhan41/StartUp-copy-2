# 👕 TeesX — Full-Stack Clothing Store

TeesX is a full-stack clothing e-commerce platform built to provide a complete online shopping experience, from product discovery to checkout and order management.

The project focuses on building a real-world e-commerce system with a responsive frontend, secure backend APIs, database integration, authentication, and online payment functionality.

---

## 🚀 Live Project

🌐 **Website:** https://startup-copy-2-frontend.onrender.com/

---

## ✨ Features

### 🛍️ Customer Features

- Browse clothing products
- Product details and images
- Product search and filtering
- Add products to cart
- Update cart quantities
- User registration and login
- Secure authentication
- Address management
- Order placement
- Order history
- Online payment integration
- Responsive design for desktop and mobile

### 🔐 Authentication

- User registration
- User login
- JWT-based authentication
- Secure HTTP-only cookies
- Protected routes
- User session management

### 💳 Payment

- Razorpay payment integration
- Online payment processing
- Payment verification
- Order creation after successful payment

### 👨‍💼 Admin Features

- Admin authentication
- Product management
- Add, update and delete products
- Manage product information
- Manage orders
- View customer orders
